Com contribuir

La Biblioteca Universal Arion és un projecte col·laboratiu. Qualsevol persona hi pot ajudar, tant si sap idiomes com si no. Tota la coordinació passa pel repositori de GitHub.

1. Revisar traduccions

Llegeix les traduccions publicades i, si hi trobes errors o millores, obre una incidència o proposa un canvi directament.

2. Proposar obres noves

Obre una incidència amb l'etiqueta nova-obra i indica el títol, l'autor, la llengua original i per què creus que val la pena traduir-la. Cal que el text original sigui de domini públic.

3. Reportar errors

Descriu el problema amb claredat i, si és visual, acompanya'l d'una captura de pantalla. Indica l'obra i el passatge concret sempre que puguis.

4. Millorar el codi

Fes un fork del repositori, crea una branca descriptiva, fes-hi els canvis i els tests, i envia una pull request. El repositori inclou una configuració de pre-commit amb lint de Python i shell i detecció de secrets.

Comunicació

Incidències per a errors i propostes concretes, discussions per a converses generals i pull requests per a canvis de codi o de contingut.
